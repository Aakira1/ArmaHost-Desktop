ARMAHOST DESKTOP

Download the installer or portable executable from:
https://github.com/Aakira1/ArmaHost-Desktop/releases/latest
Open Setup to install, or Portable to run without installation. Node.js is not required.
The source download does not include dist; npm run build generates it.

For source development: install Node.js 22+, then open Start.bat.
Open Demo.bat to try the controls without an Arma installation.

Use Setup to select game and dedicated server executables with the Browse buttons.
Save configuration, then start the server from Overview.
Read README.md for desktop features and verification details.
