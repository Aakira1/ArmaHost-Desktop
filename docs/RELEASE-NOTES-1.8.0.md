# ArmaHost Desktop 1.8.0

## Co-op starter: play co-op without hunting for missions
A dedicated server can only run missions in its `MPMissions` folder, and Steam puts none there. Without a mission, friends see an empty Role Assignment screen.

**Missions › Co-op starter** writes a ready co-op mission into your server and selects it in one click:
- **Maps:** Altis, Stratis, Malden, Virtual Reality, Tanoa (Apex DLC) or Livonia (Contact DLC).
- **Slots:** 2–16 playable squad slots (Team Leader, Medic, Autorifleman, Riflemen…). Empty slots stay empty.
- **Base:** a start point found automatically on open ground near the map's airfield or a town, with a respawn marker there (15-second respawn).
- **Arsenal crate:** pick any gear at the base.
- **Zeus for the admin:** type `#login` in chat, then press **Y** to spawn enemies, objectives and vehicles. Zeus moves to whoever is logged in as admin.

The mission is a plain folder (`ArmaHost_Coop.<Map>`) in `MPMissions`, so you can open and edit it in the Eden editor. ArmaHost never overwrites a folder it didn't create.

Starting without a mission now points you to the Co-op starter.
