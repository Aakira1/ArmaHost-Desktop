# ArmaHost Desktop 1.8.1

- **Join passwords are optional.** You can host for your home network or friends elsewhere without setting a password. Leave the field empty, and anyone with your address can join. Starlink hosting no longer needs a password either.
- **Missions are optional (from 1.8.0).** Start runs the server with or without a mission. Without one, pick it in game with `#login`, then `#missions`, or use **Missions › Co-op starter**.
