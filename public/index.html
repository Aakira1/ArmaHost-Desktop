Network hosting

Normal network: host on your LAN or directly over the internet.

NORMAL NETWORK

Normal network setup

  1. Enable network connections below and set a join password.
  2. For LAN play, friends use this PC’s LAN IP. No router forwarding is needed.
  3. For internet play, reserve this PC’s LAN address in your router. Forward the game UDP ports shown below to that address, then enter your public IPv4 above.

Starlink direct setup — no VPN software

  1. Enable public IPv4 on your eligible Starlink service.
  2. Use a router that supports port forwarding. The Starlink router itself does not; if needed, connect a suitable router and use Starlink bypass mode.
  3. Reserve this PC’s LAN address in that router, forward the game UDP ports below to it, then enter the public IPv4 shown in your Starlink account/router.

Public IPv4 is required for direct incoming connections. A 100.64–100.127.x.x WAN address is CGNAT and cannot accept ordinary port forwarding.

Refresh hosting details to see this PC’s LAN addresses and the game ports.

Optional VPN route for connections without public IPv4

Friends need access to this host through the same VPN. Then use the VPN address in Arma 3 Direct Connect.

Save your network settings, then refresh to generate connection details.

Save a server executable and enable network hosting to generate a scoped Windows Firewall command.

Run the firewall command in administrator PowerShell. Router forwarding is configured in your router. Restart after saving network changes. Use the live connection panel and a friend’s in-game test to confirm access.

Getting started

1 / Install prerequisites

Use Windows, Node.js 22 or newer, and your existing Arma 3 and Arma 3 Server installations. Keep Steam signed in. No game content is bundled.

2 / Configure paths

Open Setup, detect Steam installs or paste your executable paths, then save. Start without mods. Leave the mission blank to select one in game.

3 / Host & join

Start the server, review its logs, then Join in Arma 3. Process running does not prove it is ready. If the game is already open, use Multiplayer → Direct Connect with 127.0.0.1 and your game port.

BattlEye and mods

Direct launch may prompt a BattlEye restart. Use the official Arma launcher with BattlEye enabled, select the same game mods and Direct Connect. This utility does not bypass Steam or BattlEye.

Local vs LAN

The dashboard always binds to localhost. Local-only game mode is the default. LAN mode enables game network interfaces and requires a password; firewall/router changes are your choice and are never automatic.

Stopping safely

Save through your mission before stopping. Stop and restart terminate the owned server process; they do not issue a graceful in-game shutdown. Quit stops that process and closes the manager. Your separately launched game is left alone.

Private local data

Settings, presets and generated server.cfg contain plain-text passwords. Protect data/ and do not share your private dashboard link. Raw Arma RPT files may contain paths, player identifiers or other sensitive data.

Read README.md and docs/TROUBLESHOOTING.md in the ZIP for more details.
